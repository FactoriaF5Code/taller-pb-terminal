# 📖 Glosario

Términos del taller, por orden alfabético. Para los comandos, consulta la [chuleta](chuleta.md).

| Término | Significado |
|---|---|
| **Alias** | Nombre corto que apunta a otro comando. En PowerShell, `ls` es un alias de `Get-ChildItem`. |
| **Argumento** | Lo que va detrás de un comando y le dice sobre qué actuar. En `cd Downloads`, el argumento es `Downloads`. |
| **Bash** | Shell habitual en Linux. |
| **Branch (rama)** | Línea de trabajo paralela dentro de un repositorio de Git. Permite probar cambios sin tocar la versión principal. |
| **CLI** | *Command Line Interface*. Interfaz de línea de comandos: se controla el ordenador escribiendo órdenes. |
| **Clonar** | Descargar un repositorio completo, con su historial, de GitHub a tu ordenador (`git clone`). |
| **Comando** | Orden que escribes en la terminal. En realidad es el nombre de un programa. |
| **Commit** | Instantánea guardada de los cambios de un repositorio, con fecha, autoría y mensaje. |
| **Comodín** | Símbolo que representa otros caracteres. `*` es cualquier texto y `?`, un solo carácter. |
| **Directorio** | Sinónimo de carpeta. |
| **Directorio de trabajo** | La carpeta en la que está la terminal en cada momento. Se consulta con `pwd`. |
| **Extensión** | Parte final del nombre de un archivo que indica su tipo: `.pdf`, `.txt`, `.sh`. |
| **Fork** | Copia de un repositorio ajeno en tu cuenta de GitHub. Sobre ella sí puedes subir cambios. |
| **Gestor de paquetes** | Programa que instala, actualiza y desinstala otros programas desde la terminal: `winget`, `brew`, `apt`. |
| **Git** | Programa de control de versiones. Guarda el historial de cambios de una carpeta. |
| **GitHub** | Servicio web que aloja repositorios de Git y permite colaborar sobre ellos. |
| **GUI** | *Graphical User Interface*. Interfaz gráfica: ventanas, iconos y ratón. |
| **Kernel (núcleo)** | Parte central del sistema operativo. Habla directamente con el hardware. |
| **Log (registro)** | Archivo donde un programa anota lo que hace, línea a línea y con fecha. Se revisa con `tail` y `grep`. |
| **Merge** | Incorporar los cambios de una rama o de una pull request a otra. |
| **Opción (flag)** | Modificador de un comando. Empieza por `-` o `--`. En `ls -a`, la opción es `-a`. |
| **Origin** | Nombre que Git da por defecto al repositorio de GitHub del que clonaste. |
| **PATH** | Lista de carpetas en las que la shell busca los programas. |
| **PID** | *Process ID*. Número que identifica a un proceso. Se usa para cerrarlo. |
| **PowerShell** | Shell de Windows. |
| **Proceso** | Programa en ejecución. |
| **Prompt** | Texto que muestra la terminal cuando espera una orden. Acaba en `%`, `$` o `>`. |
| **Pull request** | Propuesta de cambios de tu fork o rama al repositorio original, para que quien lo mantiene la revise. |
| **Push / pull** | Subir tus commits a GitHub / bajar los commits nuevos de GitHub. |
| **Raíz** | Carpeta de la que parte todo el sistema de archivos: `/` en Mac y Linux, `C:\` en Windows. |
| **README** | Archivo de presentación de un repositorio. Es lo primero que muestra GitHub. |
| **Repositorio** | Carpeta de proyecto gestionada con Git, con todo su historial. |
| **Ruta absoluta** | Dirección completa de un archivo o carpeta desde la raíz. |
| **Ruta relativa** | Dirección de un archivo o carpeta desde el directorio de trabajo. |
| **Script** | Archivo de texto con una secuencia de comandos que se ejecutan de una vez. |
| **Shell** | Programa que interpreta los comandos que escribes: `zsh`, `bash`, `PowerShell`. |
| **Sistema de archivos** | Forma en que el sistema operativo organiza los archivos: un árbol de carpetas. |
| **Sistema operativo** | Programa principal del ordenador. Gestiona hardware, programas, usuarios y archivos. |
| **sudo** | Comando de Mac y Linux para ejecutar otro comando con permisos de administrador. |
| **Terminal** | Ventana donde se escriben los comandos. También se llama consola. |
| **Token** | Clave larga generada por GitHub que sustituye a la contraseña al usar Git desde la terminal. |
| **Tubería (pipe)** | El símbolo `\|`. Envía la salida de un comando como entrada del siguiente. |
| **zsh** | Shell por defecto en macOS. |
