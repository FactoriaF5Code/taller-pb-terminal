## 🧭 Cómo funciona cada módulo

Todos los módulos tienen la misma estructura:

1. **La idea**: el concepto en pocas líneas. Tu docente lo explica en clase.
2. **Los comandos**: una tabla con dos columnas, una para **Mac / Linux** y otra para **Windows (PowerShell)**. Usa siempre la columna de tu sistema.
3. **🧪 Pruébalo**: pruebas cortas para escribir en tu terminal. Cada una dice qué deberías ver.
4. **⚠️ Errores típicos**: lo que te va a pasar y cómo salir.
5. **🎯 Reto**: para practicar sola/o o en grupo (salas de Zoom).


---

## ⚡ Las 5 reglas de la terminal

1. Escribe el comando y pulsa **Enter**. Hasta que no pulses Enter, no pasa nada.
2. Escribe **exactamente**. Un espacio o una letra cambian el resultado. En Mac y Linux, las mayúsculas importan.
3. **Silencio = éxito.** Muchos comandos no dicen nada cuando funcionan.
4. **Flecha ↑** repite el comando anterior. **Tab** completa los nombres por ti.
5. **Ctrl + C** cancela lo que esté pasando. Úsalo si la terminal se queda "pensando".
